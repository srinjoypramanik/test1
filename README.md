# Uber-inspired Style Splash Screen

A simple and modern **Uber-inspired Splash Screen** built using **Flutter** and **Dart**.

This project was created as a practice project to learn Flutter UI development, animations, navigation, assets, and basic widget layout.


## Features

- Clean black and white Uber-style design
- Animated logo appearance
- Logo scale animation
- Logo fade-in animation
- Circular loading indicator
- Splash screen timer
- Automatic navigation to the Home Page
- Custom logo image using Flutter assets
- Simple Home Page with AppBar



## Technical Stack

- Flutter
- Dart
- Android Studio
